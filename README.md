# BIGBEEZARR portfolio, source

Pipeline for https://bigbeezarr.com (GitHub Pages, published from `main`; the old address bigbeezarr.github.io redirects there). `python3 build.py` writes `index.html`
from `src.html` and the data; `python3 gh_build.py --site <main checkout>` wraps it for GitHub Pages.
Automatic updates from Lightroom exports: see `AUTOMATION.md`.
